# ERC Mk-V Worksheet Inventory

## Audit scope and method

- Audited the supplied workbook `ERC_MkV_Line_Tracker R0_10102026.xlsx` locally with `openpyxl`, loading formula and cached-value views.
- Read the live spreadsheet `ERC_MkV_Line_Tracker R0_10102026` through the configured service account using the Sheets API read-only scope. Each tab was requested individually. No spreadsheet values were changed.
- Live audit date: 2026-10-17.
- All 17 live tabs were individually readable. Live worksheet IDs below are Google `sheetId` values; they are not the local Excel worksheet IDs (the workbook XML lists local IDs 1-17).
- Live row extents and tab names matched the local workbook. Header rows matched the local workbook for all tabs; `Production Dashboard` is a mixed dashboard/table sheet, so only columns A-F on row 7 are tabular headers. The adjacent G-H cells contain summary formula labels/results and are not columns in that table.
- Row counts below are structural counts, not normalized business record counts. Dashboard sheets contain presentation rows; formulas can return blank strings; titles and explanatory notes are not data records.
- Local Excel formulas were not recalculated by the Python workbook reader. Cached values exist for many formulas but not all, especially array formulas and formula-mirror rows. The live Sheets API returns calculated values. Do not treat a missing local cached result as a live zero.

## Audit findings and limitations

1. All 17 live worksheets were individually retrieved successfully with the configured read-only service account. Every live tab name and live Google `sheetId` was discovered from spreadsheet metadata; data was requested by tab title, not by treating the numeric ID as a name.
2. Live returned row extents agree with the supplied workbook's row extents. Header rows match, except the mixed `Production Dashboard` requires treating A-F as its daily table while KPI cells occupy additional columns; a raw row-wide comparison there compares a live formula result with an Excel formula string, not a header mismatch. The Phase 1 source view therefore uses a raw grid for mixed dashboards rather than presenting these cells as one table.
3. Structural agreement does not prove every source value is identical. Google Sheets recalculates formulas; the downloaded workbook can have absent/stale cached formula results. Business-value reconciliation remains a per-phase validation task.
4. The duplicated Production Order tab is exactly equal cell-for-cell in the supplied workbook. Live counts are structurally equal as well; do not sum the two tabs.
5. Heat/lot composite keys are unique in both inspected reference and RM plan data; all 33 RM plan heat/lot pairs match the reference. Machine pair joins are exact for all 31 consumables pairs and 10 distinct live Entries pairs.
6. Data-quality cautions include missing historical downtime durations, exact duplicate downtime records, an explicit November 2024 gap, formulas with incomplete local cached results, an example-only Capacity Change Log row, example shutdown rows, and a consumables list described by the workbook as an assumed-category starting list.
7. Existing local repository changes were already present at audit start. They are preserved; no credentials, login data, or live sheet content beyond structural metadata are included in this inventory.
